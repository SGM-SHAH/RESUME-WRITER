# Resume Writer

A dynamic, interactive Resume Generator web application built with vanilla HTML, CSS, and JavaScript.

## Features

- **Live Preview** — See your resume update in real-time as you type
- **Editable Sections** — Personal info, education, experience, skills, and hobbies
- **Clean Design** — Professional resume layout ready for printing
- **No Dependencies** — Pure HTML/CSS/JS, no frameworks required

## Getting Started

Simply open `index.html` in your browser to start building your resume.

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
